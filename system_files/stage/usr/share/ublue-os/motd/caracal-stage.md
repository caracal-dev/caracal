# Caracal Stage

This image boots to console mode for stage use.

Run `ujust first-run` once as your regular user, then log out and back in so
audio/realtime groups apply.

Run `caracal-stage` from a TTY to start the Wayfire performance session. Carla
starts automatically and can be relaunched with Super+D. Use Super+Enter for a
terminal, Super+Tab for the window overview, and Super+K for the optional
virtual keyboard when installed. Three-finger swipes are enabled through
Wayfire's swipe workspace plugin when the active hardware reports compatible
touch gestures.
